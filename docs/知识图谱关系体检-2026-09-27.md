# 初中物理知识图谱关系合理性体检

日期：2026-09-27

## 体检目标

本次体检不按“教材章节出现顺序”机械连线，而按以下四类关系重新判断：

1. **前置关系 prerequisite**：后一个知识点确实需要前一个知识点才能理解或操作；
2. **因果关系 causal**：前一个概念能解释后一个现象或应用，但不是严格学习前置；
3. **并列关系 parallel**：同一上位概念下的不同分支、类型、情形或对照；
4. **跨模块关系 cross_module**：不同物理模块之间确有明确物理联系。

重点处理“本应一对多 / 多对一，却被错误串成单链”的情况，并清理关键词误连、重复边和悬空边。

## 本轮主要发现

### 1. 教材顺序被误当成知识依赖

典型问题包括：

- 重力 → 弹力 → 摩擦力 → 受力分析
- 音调 → 响度 → 音色
- 串联电路 → 并联电路
- u>2f → f<u<2f → u<f
- 轮船 → 潜水艇 → 气球飞艇
- 杠杆 → 滑轮 → 滑轮组 → 斜面
- 太阳能 → 核能 → 核聚变/裂变 → 可再生/不可再生

这些关系已经改为“共同前置节点 + 分支”或“并列比较”。

### 2. 汇聚型方法节点连接不足

重点修正：

- **受力分析**：由力的示意图、重力、弹力、摩擦力共同汇入；再分流到二力平衡、力与运动状态、同一直线二力合成和压力分析。
- **欧姆定律**：由电流、电压、电阻共同汇入。
- **密度测量**：由密度、质量测量、长度/体积测量共同支撑。
- **物态变化中的能量转化**：由熔化/凝固、汽化/液化、升华/凝华三类变化共同汇入。
- **凸透镜成像规律**：分叉到三种物距情形，再分别连接照相机、投影仪、放大镜。

### 3. 并列概念被错误串联

已重点改为并列关系的包括：

- 匀速运动 / 变速运动
- 时间测量 / 长度测量
- 音调 / 响度 / 音色
- 重力 / 弹力 / 摩擦力
- 液体压强 / 大气压强
- 轮船 / 潜水艇 / 气球飞艇
- 杠杆 / 滑轮 / 斜面 / 轮轴
- 熔化凝固 / 汽化液化 / 升华凝华
- 凸透镜 / 凹透镜
- 三种凸透镜成像物距情形
- 串联电路 / 并联电路
- 电流表 / 电压表
- 电流磁效应 / 磁场对电流作用
- 太阳能 / 核能

### 4. 清理关键词误连和悬空边

删除或替换了多组明显不成立的关系，例如：

- 阿基米德原理 ↔ 水的比热容
- 摩擦力 ↔ 磁现象
- 凸透镜成像规律 ↔ 欧姆定律
- 透镜 ↔ 电流
- 牛顿第一定律 ↔ 热学能量守恒
- 电流磁效应 ↔ 牛顿第一定律
- 能源分类 ↔ 功
- 液体压强 ↔ 沸点与气压（改为“大气压强 ↔ 沸点与气压”）
- 光的直线传播 ↔ 速度（改为“光速 ↔ 速度”）
- 声音传播 ↔ 光速（改为“声速 ↔ 光速”）

同时删除了指向不存在节点的悬空关系。

## 数据结构原则

现在以 `data/knowledge/知识点数据库.json` 中的 `prerequisites` / `follow_ups` 作为学习路径元数据，
以 `knowledge/关系修正数据库.js` 作为运行时关系校正层。

校正层中的 `auditAdd` 对同一节点对具有最终解释权，避免原始启发式关系覆盖人工校准结果。

## 后续维护要求

新增或修改知识点后，应运行：

```bash
node tools/audit-knowledge-graph.js
```

若出现重复边、悬空内部边、孤立节点或 prerequisite 元数据不一致，应先修复再发布。
