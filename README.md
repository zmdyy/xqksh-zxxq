# 学情可视化 × 知识星球（整合工作仓库）

本仓库用于在不改动原有两个仓库的前提下做整合开发。

## 当前基线
- 学情可视化系统：复制自 `zmdyy/-`
- 知识点数据：复制自 `zmdyy/zsxq1`
- 物理知识点：183 个
- 原始仓库保持不动；后续整合功能只在本仓库迭代。

## V1 已加入：题目—知识点轻量标注
位置：**小题分析 → 小题统计**。

每道题：
1. 原则上只选 1 个主知识点；
2. 确有诊断意义时，可补 1–2 个关联知识点；
3. 可选填“候选错误模型”；
4. 标签保存在浏览器本地，并可导出/导入 JSON；
5. 历史同题号/同表头只提供“复用提示”，不会自动套用，避免不同考试同题号误标。

知识点选项直接来自本仓库 `data/knowledge/知识点数据库.json` 的副本。
